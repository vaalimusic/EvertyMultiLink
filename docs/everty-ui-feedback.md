# Пожелания к Everty UI от команды Everty MultiLink

Проект — настольный VPN-клиент для Windows и macOS. Обратная связь собрана по исходникам MultiLink и подключённой к нему версии Everty UI 0.1.0. Повторяющиеся сценарии — списки серверов и маршрутов, формы редактирования и компактное окно подключения.

## В первую очередь

### 1. Готовые поля ввода для форм

В Everty UI уже есть `TextEdit` и `TextField`. В MultiLink часть обработки и отрисовки поля остаётся в приложении — горизонтальная прокрутка к каретке, отрисовка выделения, буфер обмена и обработка ввода через IME. Хотелось бы использовать через один API однострочное поле, многострочное поле и защищённое поле для PIN. Для буфера обмена достаточно общего интерфейса, который приложение связывает с платформой.

**Сценарии для проверки** — вставка длинной ссылки подписки, редактирование многострочной заметки, ввод через IME с отображением композиции, ввод PIN с маской. Проверить перемещение и выделение мышью, Undo/Redo и стандартные сочетания Windows и macOS.

### 2. Прокручиваемый список с готовым взаимодействием

В библиотеке есть `ScrollArea` и `VirtualList`. В MultiLink списки серверов и маршрутов всё ещё используют свой расчёт ползунка и обработку его перетаскивания. Нужен пример или готовая связка для пиксельной прокрутки колесом и тачпадом, перетаскивания ползунка и отсечения кликов за пределами видимой области. Стабильный идентификатор строки пригодится, чтобы сохранить выделение и фокус после фильтрации или обновления подписки.

**Сценарий для проверки** — прокрутить длинный список, выбрать сервер клавиатурой, обновить данные и сохранить выделение, если сервер остался в списке.

### 3. Модальные формы с управлением фокусом и адаптивной шириной

`PopupManager` даёт размещение всплывающих элементов и возврат фокуса. Для форм MultiLink пригодится готовое модальное окно с фоном, начальным фокусом, циклом Tab / Shift+Tab внутри окна и возвратом к вызвавшей кнопке. Ширина должна зависеть от доступного места, длинный заголовок должен переноситься, а содержимое — прокручиваться, если оно выше окна.

**Сценарий для проверки** — открыть редактирование правила с длинным именем при масштабе 150–200%, дойти до кнопки сохранения и закрыть форму клавишей Esc.

### 4. Отзывчивость при вводе и наведении

Сейчас MultiLink при обновлении кадра строит список команд отрисовки и копирует весь буфер окна. Хотелось бы иметь штатный способ запросить отрисовку только после изменения состояния и переиспользовать результаты раскладки, когда изменилась каретка, подсказка или состояние кнопки. Стенд с метриками раскладки, растеризации и показа кадра поможет измерять эффект и ловить регрессии.

**Сценарий для проверки** — быстро печатать в поиске и перемещать указатель по кнопкам на экране с длинным списком серверов при масштабе 100% и 200%. Записать время от события до обновления кадра. Причину задержек в MultiLink пока не измеряли.

## Следом

### 5. Единые элементы управления для настроек и таблиц

К имеющимся `Button` и `IconButton` пригодятся переключатель, чекбокс и выпадающий список с поиском. Для кнопок с иконкой нужен один способ задать размер области клика, подпись, подсказку и видимый фокус. Это сократит собственную отрисовку на экранах серверов, маршрутов и настроек.

### 6. Доступность для клавиатуры и экранных дикторов

Нужен общий способ объявить роль элемента, доступное имя, текущее состояние и порядок обхода. Особенно важно для кнопок без текста, переключателей и полей с ошибкой. Практический пример — открыть редактор маршрута, выбрать сервер и сохранить правило только клавиатурой, с озвучиванием элементов в Narrator и VoiceOver.

### 7. Один пример интеграции с winit

Полезен небольшой пример, где вместе работают форма, виртуальный список, прокрутка, подсказки и модальное окно. Он должен показывать, как передавать события указателя, клавиатуры и IME, запрашивать перерисовку и учитывать смену DPI. По такому примеру проще переносить на общие компоненты уже написанные экраны.

## Места в MultiLink

- [`ui.rs`](../crates/multilink-app/src/ui.rs) — рисование полей, подсказок, кнопок, переключателей и модальных форм.
- [`scrolling.rs`](../crates/multilink-app/src/scrolling.rs) — расчёт ползунка для списков.
- [`main.rs`](../crates/multilink-app/src/main.rs) — события окна, ввод с клавиатуры, буфер обмена и отрисовка.
