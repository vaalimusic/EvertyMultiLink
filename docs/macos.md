# Everty MultiLink для macOS

Сборка для архитектуры текущего Mac. На Apple Silicon используется arm64.
Для повторной сборки: `bash installer/build-macos.sh` (Rust, Xcode Command Line Tools).
Скрипт загружает Mihomo v1.19.33 из официального релиза и проверяет SHA-256.

## Установка и подключение

1. Распакуйте ZIP и перенесите **Everty MultiLink.app** в «Программы».
2. Откройте приложение, добавьте подписку или VLESS-ссылку и подключитесь.
3. При подключении подтвердите системный запрос macOS. Права администратора
   получает только сетевой вспомогательный процесс; интерфейс остаётся пользовательским.
4. Основной режим **TUN** направляет трафик Mac через `utun198`, включая DNS и IPv6.
   Ручная настройка прокси не требуется. После обновления ранней сборки TUN включается
   по умолчанию; режим можно изменить в настройках приложения.
5. **Системный прокси** можно использовать отдельно для браузеров и совместимых приложений.
   MultiLink включает его автоматически и возвращает прежние настройки при отключении.
   Для ручного режима без TUN и системного прокси остаётся адрес **127.0.0.1:17890**.

## Поддержка в этой сборке

- Нативный интерфейс, импорт подписок, маршрутизация и встроенное ядро Mihomo.
- Настройки и подписки сохраняются в Связке ключей macOS (при запросе разрешите доступ).
- Нативные диалоги импорта/экспорта файлов, открытие ссылок, сочетания Cmd+C/V/X/A.
- Системный язык определяется по настройкам macOS, в том числе при запуске через Finder.
- Монохромный значок в строке меню автоматически подстраивается под светлую и тёмную тему.
  Полая точка означает отключение, заполненная — активное соединение.
- Из меню доступны подключение, окна, настройки и копирование адреса прокси.
- Закрытие окна и Cmd+W скрывают приложение, сохраняя соединение.
  Открыть окно снова можно через значок в строке меню или Dock.
- Cmd+, открывает настройки, Cmd+Q полностью завершает приложение и соединение.
- В настройках можно включить запуск при входе в macOS. Сначала перенесите приложение
  в «Программы», затем включите автозапуск. Изменение применяется при следующем входе.
  Файл автозапуска: `~/Library/LaunchAgents/ru.everty.multilink.plist`.
- Рабочие файлы: `~/Library/Application Support/Everty/MultiLink`.
- TUN, автоматические HTTP/HTTPS/SOCKS-прокси и восстановление исходных DNS/прокси.
- Правила доменов и IP, имена процессов Mac без `.exe`, полные пути к исполняемым
  файлам и кнопка выбора `.app`. Выбранный пакет охватывает процессы внутри его `Contents`,
  включая встроенные сетевые помощники. Общие системные сетевые процессы нужно добавлять
  отдельно. Изменение правил применяется без перезапуска соединения.
- Независимый процесс восстановления останавливает ядро и возвращает настройки
  при аварии сетевой службы. Локальные вспомогательные ядра также завершаются после
  исчезновения приложения. Сон системы при активном соединении предотвращается.
- Сборка имеет локальную ad-hoc подпись, без Apple Developer ID и нотариализации.
  macOS может потребовать разрешить запуск в разделе «Конфиденциальность и безопасность».

Лицензии и исходники Mihomo находятся внутри приложения: `Contents/Resources/Licenses`.
Для диагностики есть команда `Contents/MacOS/multilink-app --smoke-macos-network`.
Она использует сохранённую подписку, временно проверяет TUN, доменные и процессные
правила, системный прокси и аварийное восстановление, затем отключается. Не запускайте
её одновременно с обычным подключением MultiLink.

## Приём конфигурации по QR / Wi‑Fi

Mac и отправитель должны быть в одной локальной сети. QR использует IPv4 физического
Wi‑Fi/Ethernet-адаптера, а не адрес VPN. Если сторонний VPN блокирует локальную сеть,
разрешите LAN в его настройках. После обновления приложения откройте новый QR.
Страница отправки показывает успех только после импорта серверов на Mac; ошибки
скачивания подписки или формата конфигурации возвращаются отправителю.
Передача из Android сохраняет название, срок подписки и выключенные серверы.
Ожидание скачивания поддерживает старые Android-клиенты с коротким сетевым тайм-аутом.
При передаче отдельных серверов открывается раздел «Серверы»; для HTTPS-подписки —
раздел «Подписки». Загрузка подписки учитывает системный прокси macOS и имеет прямой
резервный путь.

VLESS-ссылки с параметром `fm` импортируются без применения фрагментации FM.
Адрес, ключи, TLS/REALITY и поддерживаемый транспорт сохраняются. Приложение
показывает предупреждение, а Wi‑Fi-ответ содержит список предупреждений.
Если FM требуется для обхода блокировки, такой сервер может не подключиться.
Другие неподдерживаемые параметры и транспорты по-прежнему не удаляются автоматически.
